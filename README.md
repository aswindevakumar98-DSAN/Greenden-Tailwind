# 🌿 Greenden — Plant & Flower Website

A responsive plant and flower e-commerce website built using **HTML and Tailwind CSS**.

🔗 **Live Website:** https://aswindevakumar98-dsan.github.io/Greenden-Tailwind/

## 📌 About The Project

**Greenden** is a modern and responsive plant/flower website designed to showcase natural and artificial flowers, plants, and related products.

The project was created to practice and demonstrate **responsive web design and Tailwind CSS utility classes**, including layouts, spacing, typography, responsive navigation, grids, hover effects, and reusable UI sections.

## ✨ Features

* 🌿 Responsive navigation bar
* 🏠 Hero / landing section
* 🌱 About Us section
* 📦 Large assortment section
* 🚚 Free & fast shipping information

## 🚀 How To Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/aswindevakumar98-dsan/Greenden-Tailwind.git
```

### 2. Navigate into the project

```bash
cd Greenden-Tailwind
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the project

Open `index.html` in your browser, or use the development workflow configured for your Tailwind CSS setup.
